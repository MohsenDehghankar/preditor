# PrEditor

A browser-based prompt editor with a tree view, local storage persistence, and optional markdown preview.

## Features
- Create folders and prompts in a tree layout
- Edit prompt text with autosave in local storage
- Toggle a side-by-side markdown preview
- Duplicate or delete prompts quickly

## Development
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview build: `npm run preview`

## Notes
- Prompts are stored in your browser local storage on this device.
